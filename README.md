# Fitness & ЛФК — Android APK

Приложение для домашних тренировок и лечебной физической культуры (ЛФК):
пошаговый таймер, метроном, контроль пульса через смарт-часы (BLE),
адаптивная нагрузка, 41 упражнение и 17 программ на русском и узбекском (латиница/кириллица).

## Скачать последнюю версию

**Прямая ссылка (всегда свежий APK):**
https://github.com/OneComputers/fitness-lfk-apk/releases/latest/download/Fitness_LFK.apk

Или откройте [страницу релизов](https://github.com/OneComputers/fitness-lfk-apk/releases) и скачайте `Fitness_LFK.apk`.

## Установка

1. Откройте ссылку на телефоне (Chrome)
2. Разрешите установку из этого источника, если Android спросит
3. Установите APK (подписан, обновляется поверх старых версий без удаления данных)
